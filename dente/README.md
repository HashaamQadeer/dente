# Dente (offline desktop app)

Local-first dental clinic app built with **Electron + React + TypeScript** and a local **SQLite** database.

## What’s implemented

- Top navigation tabs: **Home**, **Add Patient**, **Patients**, **Procedures**
- **Patients**
  - Create patient with validation (Name, DOB, Gender required)
  - Search by name (supports duplicate names; IDs are unique)
  - Update / Delete patients
- **Procedures**
  - Select patient
  - Add / Update / Delete procedures (name, date, cost, paid, balance)
  - Balance auto-calculates as `cost - paid` (you can override)
- **Offline**
  - Data is stored locally in SQLite at Electron’s `userData` path (file: `dente.sqlite`)

## Run (development)

From `dente/`:

```bash
npm install
npm run dev
```

## Build installer (Windows)

```bash
npm run build
```

The output is written to `dist-electron/`.

## Notes

- The app uses secure Electron settings (`contextIsolation: true`) and exposes a minimal API via preload (`window.dente`) for database operations.
